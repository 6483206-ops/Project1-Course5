Rock Paper Scissors Game ✊📄✂️

My first C++ project — a simple Rock Paper Scissors game.

This project was created as part of Course 5 by Programming Advices (Abu-Hadhoud) while learning C++ and practicing programming fundamentals.

🎮 About The Game

The player chooses one of three options:

- ✊ Rock
- 📄 Paper
- ✂️ Scissors

The computer randomly chooses an option, and the game determines the winner based on the classic rules:

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock

🛠️ Concepts Practiced

Through this project, I practiced:

- Variables and data types
- "if" / "else"
- "switch"
- "while" loops
- "enum"
- Functions
- Arrays
- Random number generation
- User input and output
- Basic game logic
- Console colors and screen control

🚀 How To Run

1. Clone the repository.
2. Open the project in a C++ IDE such as Visual Studio.
3. Compile and run the program.
4. Follow the instructions displayed in the console.
